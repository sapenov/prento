# Timer, measurement and QA update plan

**Goal:** Correct submillisecond sink sleeps, verify scheduling/credit behavior through actual TCP collector integration, expose latency breakdown and paired comparisons, rerun several workload seeds, and deliver a self-contained QA ZIP.

**Architecture:** Preserve four modes and the existing whole-batch service model. A clock-injectable bounded pause helper permits deterministic timer tests.
