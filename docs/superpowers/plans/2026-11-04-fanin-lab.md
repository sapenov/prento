# Fan-in Lab Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement task-by-task.

**Goal:** Deliver the laptop C++ network experiment specified in DESIGN.md.
**Architecture:** Shared admission/scheduling core; three executable modes over TCP; Python standard-library orchestration and report generation.
**Tech Stack:** C++20, POSIX sockets, Make/CMake, Python 3, Docker Compose.
**Spec:** ../../../DESIGN.md

## Global Constraints
- Four fair admission/policy combinations; real TCP; no Homa transport dependency.
- Explicit bounded payload reservations, producer queues, message validation and terminal outcome ledger.
- No invented benchmark improvements or unverified container claims.

## Review Focus
- Oversized, truncated and corrupt payloads must fail without successful acknowledgment.
- Peer loss and blocked producers must terminate within configured timeouts.
- Priority must retain a bounded opportunity for bulk work.
- Result generation must account for drops and unknown delivery, not report only successful latency.
- One sink must provide a shared rate limit across concurrent clients.

## Task 1: Admission and scheduling core
- [x] Write tests for reservation cap, release, oversize, FIFO and priority/fairness; observe failure before implementation.
- [x] Implement core in include/fanin/core.hpp; run native unit suite.

## Task 2: Network application
- [x] Write Python real-process tests of all four modes, checksums, size validation and sink loss; observe missing executable failure.
- [x] Implement include/fanin/net.hpp and src/{main,collector,producer,sink}.cpp. Define fixed binary wire header, checksums and bounded timeouts.
- [x] Run unit and integration suite, address root causes of failures.

## Task 3: Reproducible benchmark and report
- [x] Write report tests with literal fixture outcomes; verify missing implementation failure.
- [x] Implement scripts/bench.py and scripts/report.py. Capture workload/environment/raw outcomes and RSS; generate JSON, Markdown and SVG without third-party packages.
- [x] Run all four combinations over steady, burst, slow-sink and outage scenarios; publish observed limitations.

## Task 4: Packaging and handoff
- [x] Add Make/CMake, Docker/Compose, optional Kubernetes example and CI; document exact commands.
