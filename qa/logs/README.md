# Execution logs

Start with the [verification summary](../VERIFICATION.md) for the logs supporting each check. Individual logs record the suite and commands executed; test counts apply to that execution. Additional logs support measurement provenance and diagnostic investigation.

These are actual execution logs, including failed diagnostic startup attempts and intentional mutation-test failures. Logs that contained the local project/workspace prefix have public copies with those prefixes replaced by `<PROJECT_ROOT>` / `<WORKSPACE>`. Paths of temporary diagnostic builds may be replaced by `<TEMP_BUILD>`. Content, exit outcomes and timing values are otherwise retained.

The archive manifest covers the normalized copies supplied with each bundle. Raw outcome CSV and run-configuration files retain their measured bytes.
